# 🚀 Plano de Estudos: Especialista Back-end Java

Bem-vindo ao seu plano de estudos estruturado para 30 dias! Este cronograma foi desenhado para consolidar seus conhecimentos em Programação Orientada a Objetos (POO) e SQL, integrando-os ao ecossistema moderno de APIs com Spring Boot.

## 🎯 Objetivo Principal
Transformar sua base teórica e acadêmica da **FATEC MC** em competência técnica prática para o desenvolvimento de sistemas robustos, escaláveis e prontos para o mercado de trabalho, focando no ecossistema Java e bancos de dados relacionais.
